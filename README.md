# DashamLabs — Website Redesign

A modern, light‑and‑dark, awwwards‑style redesign of [dashamlabs.com](https://dashamlabs.com) — a deep‑tech materials company manufacturing advanced **silica aerogel insulation**.

Single self‑contained static page: `index.html` + `assets/` (real imagery, logo, and industry photos). Typography: **Raleway** (with Inter for numerals). Brand gradient: cyan → blue → green.

## Preview

Hosted with GitHub Pages — see the repository's **Pages** URL.

## Run locally

Any static server works, e.g.:

```bash
python3 -m http.server 4477
```

Then open <http://localhost:4477>.
